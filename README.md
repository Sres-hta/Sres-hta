## 🚀 Featured Project

### FinOps-BatchGuard

A Python and Bash batch-operations automation project modeled around financial workflows such as SWIFT ingestion, GL reconciliation, and end-of-day settlement.

- ⚙️ Resolves job dependencies and retries transient failures.
- 🎫 Converts batch failures into prioritized ServiceNow incidents, with routing and deduplication.
- 📈 Collects system health telemetry and produces CSV check-sheets and HTML shift handovers.

**Built with:** Python · Bash · SQLite · ServiceNow REST API · HTML · CSV
